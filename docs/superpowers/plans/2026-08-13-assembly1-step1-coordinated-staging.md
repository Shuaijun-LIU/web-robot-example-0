# Assembly1 Step 1 Coordinated Staging Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: execute inline with test-driven development in the current session. Do not dispatch subagents because this is a shared worktree and the user requested conflict avoidance.

**Goal:** Add one user-triggered Assembly1 action that moves all four Panda arms to role-specific pre-grasp poses without manipulating any object.

**Architecture:** A pure JavaScript choreography module owns the role/waypoint contract, offline-solved joint targets, and interpolation. A reproducible MuJoCo script solves and validates the two IK waypoints per arm against a single identical Panda model so the Web click never blocks on full-scene finite differences. A React/MuJoCo controller atomically validates all four namespaced chains and writes only actuator controls during physics steps. App-level state connects a dedicated left-side panel to the controller and existing Reset/IK behavior.

**Tech Stack:** React 19, TypeScript, Three.js, `mujoco-react`, MuJoCo WASM, Node test runner, Playwright.

## Global Constraints

- Implement only Step 1 coordinated staging; no gripper closure and no later assembly actions.
- Use real actuator controls and joint waypoints generated by the existing IK; never move an object or robot by directly editing free-body `qpos`.
- Keep all four grippers open at control value `255`.
- Show the control only for `Franka Assembly1`, below the top-left performance panel.
- Reset cancels the action and restores status to idle.
- Do not add proximity attachment, weld, magnet, scripted object following, or automatic pickup.
- Do not commit, push, or deploy this work.
