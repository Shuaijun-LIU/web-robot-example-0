# Cooperative workcell assets

This self-contained package serves Franka Demo3 (product inspection/packing),
Franka Demo4 (two-arm pot support with solid ingredient loading), and
Franka Demo5 (drawer access and order kitting).

## Franka Demo5: source-derived passive drawers

`drawer.xml` reuses the same robots, tea/coffee boxes and tray. New fixtures
reuse [RoboCasa Drawer topology and dimensioning](https://github.com/robocasa/robocasa/blob/main/robocasa/models/fixtures/cabinets.py),
`fixtures/cabinets/drawer.xml`, `CabinetDoorPanel029`, and `CabinetHandle001`.
The housing is the benchmark's parameterized primitive fixture, resized to
280 × 300 × 170 mm; the decorative front and handle are existing mesh assets,
not newly modeled props. Source snapshots and SHA-256 records are in
`drawer-sources/` and `drawer-manifest.json`.

RoboCasa fixture code is MIT (`licenses/RoboCasa-code.txt`); the panel/handle
assets are attributed to RoboCasa / Lightwheel AI under CC BY 4.0, as declared
in the [RoboCasa project license](https://github.com/robocasa/robocasa#license).
The source README is retained with the snapshots. Changes: panel dimension
scaling (same transform for visual/collision), horizontal rotation of the
unchanged handle, texture downsampling, named fixture joints and a 225 mm slide
limit. Slide damping is 10, friction loss 0.25; the drawers have no actuator or
spring closure. The source four moving box geoms keep their 0.2 kg masses;
front/handle inertia is derived from collision geometry at density 600 kg/m³.
These are simulation parameters, not physical hardware measurements.

Rebuild only Demo5 with:

```bash
uv run --with trimesh --with pillow --with numpy python scripts/build-drawer-assets.py --robocasa PATH_TO_ROBOCASA_REPO
uv run --with 'mujoco==3.3.7' --with numpy python scripts/solve-drawer-task.py
```

The base package rebuild precedes this additive builder. Existing scan/pot
scene files, geometry and motion files are not regenerated by the Demo5 builder.

## Conversion and physical assumptions

`scripts/build-cooperative-assets.py` exports source geometry to OBJ for MuJoCo,
binds the original textures explicitly, and downsamples textures to at most
1024 pixels per side. No object shape is remodeled. `manifest.json` records
source identifiers/hashes, bounds, scales, collision counts and initial poses.
The same transform is applied to visuals and collisions. Existing source
collision approximations are measured independently in the native report.

All task objects are free rigid bodies. Masses are task assumptions, not
measured physical properties: scanner 130 g; tea/coffee boxes 90/100 g;
tray 120 g; pot 550 g; carrot/tomato 55/70 g. Inertias use conservative
bounding-box estimates. Only fixtures (table, work pads) are simple primitives.
No weld, magnet, object-following constraint or scripted free-body pose is used.

The pot's collision cavity is tested by dropping a physical probe and requiring
it to rest on the inner floor below the rim. A whole-pot convex hull is never
used. Barcode inspection is a geometric pose gate, not image recognition.

`scan-motion.json` and `pot-motion.json` contain verified actuator programs.
Inspection reuses scanner `model_data0.json` functional point 1 (the optical
head center), with its transformed local -Y direction facing the product.
Demo3 dispatch is a two-fingertip outside-wall push along a continuous support
bed, not an airborne tray grasp. Demo4 keeps two real bilateral handle grasps
during loading and reverses the insertion corridor to release the handle loops.

## Rebuild

Use the existing MuJoCo Menagerie, RoboTwin and RoboCasa asset checkouts:

```bash
uv run --with trimesh --with pillow python scripts/build-cooperative-assets.py \
  --menagerie PATH_TO_MENAGERIE --robotwin PATH_TO_ROBOTWIN \
  --robocasa-objects PATH_TO_ROBOCASA_OBJECTS
uv run --with 'mujoco==3.3.7' --with trimesh --with pillow \
  python scripts/verify-cooperative-assets.py
```

Automatic task readiness is reported by each page; displaying these assets
alone does not establish successful task execution.
